# Release Notes - v1.0.0

发布日期：2026-04-30  
Git tag：`v1.0.0`

## 概览

`v1.0.0` 是项目第一个正式稳定版，目标是提供一套可本地部署、可远程 AI 代理安全调用、同时足够适合真实编码任务的 MCP 工具服务。

相较于早期里程碑版本，这个版本已经不再只是 MCP 骨架，而是补齐了：

1. 更完整的文件修改原语
2. Go 导航能力
3. 更实用的 Go workflow 执行能力
4. 更清晰的运行日志与审计滚动

## 主要能力

### MCP 与传输层

- `POST /mcp` JSON 模式
- `POST /mcp` 单次 SSE
- `GET /mcp` 长连接 stream + async `POST /mcp`
- 服务重启后的 stale session stream 自恢复提示

### 文件与代码修改

- `fs.read_file`
- `fs.write_file`
- `fs.list_dir`
- `fs.stat_path`
- `fs.make_dir`
- `fs.move_path`
- `fs.delete_path`
- `fs.search_text`
- `fs.replace_text`
- `fs.edit_lines`
- `fs.apply_unified_diff`

其中：

- `fs.edit_lines` 适合小范围行编辑
- `fs.apply_unified_diff` 适合复杂多处修改

### Go 导航

- `go.list_symbols`
- `go.find_definition`

第一版聚焦 Go-only：

- 单文件 symbols
- 按 `path + line + column` 跳定义

### Git 与执行

- Git 白名单工具：
  - `git.status`
  - `git.diff`
  - `git.log`
  - `git.add`
  - `git.restore`
  - `git.commit`
  - `git.branch`
  - `git.switch`
  - `git.pull`

- `exec.run` Go preset：
  - `go_fmt`
  - `go_mod_download`
  - `go_test`
  - `go_generate`
  - `go_build`
  - `go_vet`
  - `go_mod_tidy`
  - `go_get`
  - `go_list`
  - `go_work_sync`

- `exec.run_template` 固定模板：
  - `make_test`
  - `make_build`
  - `go_clean_testcache`

### 安全、观测与审计

- Bearer Token 鉴权
- allowed roots 路径隔离
- 浏览器 `Origin` 白名单限制
- `/healthz`
- `/readyz`
- `/debug/statez`
- JSONL 审计日志
- 审计日志按大小滚动
- 分级控制台日志：
  - `DEBUG`
  - `INFO`
  - `WARN`
  - `ERROR`

## 特别说明

这个版本默认仍基于：

- Go 1.20

以兼容本项目面向的 Windows 7 目标运行环境。
