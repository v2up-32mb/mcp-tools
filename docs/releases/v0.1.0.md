# Release Notes - v0.1.0

发布日期：2026-04-11  
Git tag：`v0.1.0`

## 概览

`v0.1.0` 是本项目的首个里程碑版本，交付了一套可本地运行的 MCP 工具集服务，面向“远程 AI 代理安全访问本地工作区”的核心场景。

这个版本重点完成了三件事：

1. 打通 MCP 协议接入
2. 提供受限但实用的工具集
3. 建立基本安全边界、审计与维护文档

## 主要能力

### 传输层

- `POST /mcp` JSON 模式
- `POST /mcp` 单次 SSE 模式
- `GET /mcp` 长连接 stream + async `POST /mcp`

### MCP 能力

- `tools/list`
- `tools/call`
- `resources/list`
- `resources/templates/list`
- `resources/read`
- `resources/subscribe`
- `resources/unsubscribe`
- `prompts/list`
- `prompts/get`
- `completion/complete`
- `ping`

### 工具集

#### 文件工具

- `fs.read_file`
- `fs.write_file`
- `fs.list_dir`
- `fs.stat_path`
- `fs.make_dir`
- `fs.move_path`
- `fs.delete_path`
- `fs.search_text`
- `fs.edit_lines`

#### Git 工具

- `git.status`
- `git.diff`
- `git.log`
- `git.add`
- `git.restore`
- `git.commit`
- `git.branch`
- `git.switch`
- `git.pull`

#### Exec 工具

- `exec.run`
- 预置 Go preset：
  - `go_fmt`
  - `go_test`
  - `go_build`
  - `go_vet`

## 安全边界

- Bearer Token 鉴权
- 允许目录限制：启动目录 + 显式白名单
- Git 固定白名单子命令
- Exec 固定 preset，不开放任意 shell
- JSONL 审计日志
